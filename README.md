# Bandwidth-Meter-and-Traffic-Analyzer
UDP-based traffic measurement application for Computer Networks Mini Project

# Problem Statement 
Develop a UDP-based traffic measurement application and compare application-level bandwidth measurements with SDN flow statistics.

# Project Expectations  
• Generate UDP measurement traffic  
• Count transmitted packets  
• Count received packets  
• Calculate throughput  
• Collect SDN flow statistics  
• Measure packet loss  
• Compare application and network measurements  
• Analyze different traffic loads  

# Protocol
UDP
